# Codealpha_hangmangam

Description:

This is a simple text-based Hangman game developed using Python.
The player has to guess the hidden word one letter at a time.

Features:

- Random word selection
- Letter guessing system
- Limited incorrect attempts
- Win and lose conditions
- Console-based gameplay

Technologies Used:

- Python

Concepts Used:

- Lists
- Loops
- Conditional statements
- Random module
- User input/output

How to Run:

1. Save the file as "hangman.py"
2. Open it in Python or Pydroid 3
3. Run the program

Example:

The game displays hidden letters using "_" and asks the user to guess letters until the word is completed or chances end.
